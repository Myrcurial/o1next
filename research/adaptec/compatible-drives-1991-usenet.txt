# WHY IT IS HERE
#   The MD-10 personality should be able to offer any ST-506/412-class drive
#   (docs/harddisk-decision.md section 7.2).  The drive table the MD-10 tools
#   ship - DRIVETBL.DAT, 126 name records, printed by tools/research/drivetbl.py
#   - is one such list; this is a second, independent one, from a period
#   source, with the manufacturers' own numbers.  Columns, as the posting
#   defines them:
#
#     CAP = capacity in FORMATTED megabytes      RATE  = transfer rate, Mbit/s
#     CYC = maximum number of cylinders          ACCESS= average access time
#     H   = number of data heads                 SPT   = sectors/track x 512 bytes
#     RWC = start reduced write current          ENC   = encoding (R=RLL, M=MFM)
#     WPC = start write precomp                  FH/HH = full/half height
#   "if it's = CYC + 1 then it is not used" applies to RWC and WPC.
#
#   Note SPT is 17 for almost every entry here, while DRIVETBL.DAT's capacity
#   formula uses 18 (docs/harddisk-decision.md section 7.2).  The two lists
#   disagree on PYXIS-13 too: 320 cylinders here, 321 in DRIVETBL.DAT.  Neither
#   is wrong - one is the drive manufacturer's number and the other is what the
#   MD-10 tools carry - and the difference is recorded rather than reconciled.

       CAP   = CAPACITY IN FORMATTED MEGABYTES
       CYC   = MAXIMUM NUMBER OF CYLINDER
       H     = NUMBER OF DATA HEADS
       RWC   = START REDUCED WRITE CURRENT
               IF IT'S = CYC + 1 THEN IT IS NOT USED
       WPC   = START WRITE PRECOMP
               IF IT'S = CYC + 1 THEN IT IS NOT USED
       ENC   = ENCODING METHOD R=RLL, M=MFM
       RATE  = TRANSFER RATE IN MEGABITS/SEC
       ACCESS= AVERAGE ACCESS TIME
       SPT   = SECTORS/TRACK X 512 bytes
       FH    = FULL HIGH FORM FACTOR
       HH    = HALF HIGH FORM FACTOR
       R     = RLL (run length limited)
       N     = NRZ (non return to zero)
       M     = MFM (modified frequency modulation)
       SA    = STAND ALONE
       Z     = ZBR
