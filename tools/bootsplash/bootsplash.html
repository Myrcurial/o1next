bootsplash

Draw a boot splash for the Osborne 1, and export it as the animation the RP2354B plays. The screen is 128×32 cells; the viewport is 52, 80 or 104 columns × 24 rows.
Click a cell, then type. Arrows move, Enter is the next row, Space is the blank, drag to select a block. A–a are graphics keys — pick one from the palette.

Pen

Graphics font — glyph = key − 65

The 33 keys A–a plus the hatch at U+00C0 — the ROM's own sui 65. A capital is therefore a glyph index and cannot be typed as a letter, which is why ROM 2.0's captions are lowercase. Click a swatch to paint with it; the hatch has no key at all.

Export

The .bin is a 32-byte header and then the frames, each byte-identical to firmware/rom-service/frame.bin — tail -c +33 of a one-frame file is that asset exactly. The header is this tool's proposal; the firmware side of #247 is not written yet.

Import

A .bin in this tool's container (or a bare 8192-byte frame), or art text in the repo's own convention. Art text cannot express a cell holding glyph 0x41–0x61; if one arrives it is reported rather than silently changed.
